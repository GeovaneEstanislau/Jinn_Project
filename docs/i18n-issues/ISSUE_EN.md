Welcome to the **Jinn OS** community!

We recently published the initial English version of our central documentation: [**`README.en.md`**](https://github.com/GeovaneEstanislau/Jinn_Project/blob/main/README.en.md).

### 🎯 Objective of this Issue
Jinn OS is an open-source, sovereign, minimalist, and preemptive **x86_64 microkernel** written entirely from scratch in modern Rust (`#![no_std]`, bare-metal). 

We want to ensure that our English documentation is clear, idiomatic, technically rigorous, and welcoming to developers and systems programming enthusiasts from across the globe.

### 🔍 How You Can Help
1. **Review Technical Accuracy & Phrasing:**
   - Verify that operating system concepts (such as *PML4 4-level paging*, *W^X memory isolation*, *PIT 100Hz preemption*, *lock-free IPC*, *VFS with transactional persistence*, and *Ring 3 Aladdin Desktop compositor*) read naturally.
   - Report any grammatical typos, awkward phrasing, or unclear descriptions.
2. **Expand Kernel & Application Development:**
   - Help write and test new hardware device drivers (VirtIO-Net, Intel E1000, NVMe, USB, AHCI).
   - Contribute to our Ring 3 graphical compositor (**Aladdin Desktop**) and native GUI applications (such as **Jinn Browser** and **Aladdin Wallet**).
   - Test Jinn OS on different hardware configurations and virtualization environments (QEMU, VirtualBox, bare-metal).
3. **Share Feedback & Ideas:**
   - Drop a comment below if you have suggestions, questions, or ideas for the architecture!
