# Política de Segurança

Se você encontrar uma vulnerabilidade de segurança, por favor reporte-a enviando um e-mail para `security@jinn.org` com detalhes e passos para reproduzir. Evite divulgar publicamente até que haja um plano de correção.

Inclua o máximo de informações possível: versão do código, passos, logs e um patch de correção se possível.
