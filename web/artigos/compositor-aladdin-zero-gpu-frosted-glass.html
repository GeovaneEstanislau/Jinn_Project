Compositor Gráfico Aladdin: Efeitos Visuais Modernos, Frosted Glass e Zero-GPU com 0 Alocações no Laço Quente

Como projetamos uma interface com estética contemporânea inspirada em elementary OS e Garuda Linux que roda suavemente em framebuffer linear sem exigir placa de vídeo dedicada.

Pilares de Design do Aladdin

  • Beleza Independente de Aceleração 3D: Composição puramente vetorial na CPU com kernels SIMD acelerados em assembly inline.
  • Zero Alocações no Laço Quente: O pipeline de composição não invoca o heap manager durante a renderização de quadros, prevenindo pausas de fragmentação.
  • Rastreamento de Regiões Sujas (Dirty Rects): Redesenho estritamente restrito aos pixels alterados, poupando até 98% da largura de banda de memória.
  • Consumo 0.00% em Ociosidade: Quando o mouse e as janelas repousam, o compositor não faz polling e coloca os núcleos em estado C1/HLT.

1. A Falácia da Dependência de GPU para Interfaces de Usuário

Os desktops contemporâneos tornaram-se extraordinariamente pesados. Sistemas operacionais corporativos exigem gigabytes de memória de vídeo apenas para desenhar cantos arredondados, docks com reflexo e janelas translúcidas.

No ecossistema Aladdin, decidimos demonstrar que a matemática correta e a otimização de cache superam a força bruta. O compositor opera sobre o framebuffer linear provido pelo bootloader Limine (resolução 1024x768 a 32 bits por pixel, BGRX/RGBA), garantindo compatibilidade imediata com qualquer máquina virtual (QEMU, VirtualBox, VMware) ou bare-metal antigo.

2. Dirty Rectangles e Composição em Camadas

Um redesenho completo de tela em 1024x768 transfere cerca de 3,14 MiB de dados por quadro. A 60 FPS, isso consumiria quase 200 MiB/s de tráfego de barramento. O Aladdin resolve este problema através de caixas delimitadoras de dano (Dirty Rects): 

pub struct DirtyRect {
    pub x: usize,
    pub y: usize,
    pub width: usize,
    pub height: usize,
}

impl DirtyRect {
    pub fn union(&self, other: &Self) -> Self {
        let x1 = self.x.min(other.x);
        let y1 = self.y.min(other.y);
        let x2 = (self.x + self.width).max(other.x + other.width);
        let y2 = (self.y + self.height).max(other.y + other.height);
        Self { x: x1, y: y1, width: x2 - x1, height: y2 - y1 }
    }
}

Quando o cursor do mouse se move, apenas a caixa da posição anterior unida à caixa da nova posição (cerca de 32x32 pixels, menos de 4 KiB) é transferida para o display físico.

3. Efeito Frosted Glass e Dock com Reflexos

O painel superior translúcido e a dock Cairo utilizam um algoritmo de mistura alfa vetorial com saturação de canal inteiro em 32 bits (ARGB). Ao evitar números de ponto flutuante (FPU) no caminho crítico, o código previne qualquer custo de salvamento de contexto de registradores SSE/AVX durante interrupções de hardware.
