## О проекте

**Jinn OS** — это операционная система с микроядерной архитектурой, созданная с нуля на современном Rust. Проект возник из необходимости построить надежную, минималистичную и формально верифицируемую вычислительную основу, где лишь строго необходимый минимум механизмов исполняется в наиболее привилегированном режиме процессора (**Ring 0**).

В отличие от традиционных монолитных ОС, в Jinn OS все сложные подсистемы — включая сетевые драйверы, файловые системы, графический оконный композитор **Aladdin Desktop** и приложения, такие как веб-браузер **Jinn Browser**, — функционируют как изолированные процессы в пространстве пользователя (**Ring 3**). Целостность системы обеспечивается аппаратной защитой страниц памяти, строгим разграничением прав и высокоскоростным неблокирующим межпроцессным взаимодействием (IPC).

## Архитектурные принципы и ключевые достижения (Alpha v0.0.3)

1. **Истинная вытесняющая многозадачность:**
   - Вытесняющий планировщик Round-Robin, тактируемый таймером PIT (100 Гц / квант 10 мс), с поддержкой локального таймера APIC.
   - Раздельная конвейерная обработка аппаратных прерываний (IRQ) и явная отправка сигнала завершения (EOI) в LAPIC для предотвращения зависания шины прерываний.

2. **Строгая изоляция памяти (PML4 x86_64 и безопасность W^X):**
   - Четырехуровневая таблица страниц (PML4) со строгим контролем канонического адресного пространства.
   - Процессы Ring 3 изолированы в каноническом пользовательском диапазоне (`>= 0x400000`) без прямого доступа к физической памяти или управляющим структурам Ring 0.
   - Повсеместное соблюдение аппаратной политики W^X (*Write XOR Execute*) для всех динамически выделяемых страниц.

3. **Принцип наименьших привилегий и канонический интерфейс системных вызовов:**
   - Ring 0 выполняет только переключение контекста, выделение физических фреймов, диспетчеризацию прерываний и обработку системных вызовов (Syscalls `0..85` через `syscall`/`sysret` с сохранением совместимости с `int 0x80`).
   - Микроядро принципиально не хранит, не обрабатывает и не принимает приватные криптографические ключи или мнемонические фразы.

4. **Неблокирующий обмен сообщениями (Lock-Free IPC):**
   - Статические очереди сообщений для каждого процесса без динамических аллокаций памяти в критическом пути передачи данных.

5. **Виртуальная файловая система (VFS) с транзакционной надежностью:**
   - Нативная параллельная поддержка файловых систем **FAT32** (`/disk`) и **Ext2**.
   - Подсистема блочного кэширования **BlockCache** с алгоритмом вытеснения LRU (Least Recently Used) для минимизации задержек дискового ввода-вывода.
   - Полная поддержка стандартных флагов доступа POSIX (`O_RDONLY`, `O_WRONLY`, `O_RDWR`, `O_CREAT`, `O_APPEND`, `O_TRUNC`).
   - Механизм транзакционной ротации файлов (`.TMP` -> `.BAK`), предотвращающий повреждение кэша, закладок, истории и cookies пользовательских приложений при внезапном сбое питания.

6. **Графическая среда Aladdin Desktop в Ring 3:**
   - Независимый оконный сервер и композитор, функционирующий полностью в пользовательском пространстве (`apps/aladdin-server`).
   - Рендеринг в высокопроизводительный линейный фреймбуфер (Linear Framebuffer), предоставляемый Limine.
   - Драйвер мыши PS/2 с конвейерным разбором пакетов, отрисовкой аппаратного курсора в реальном времени и маршрутизацией оконных событий (`Focus`, `Drag`, `Resize`, `Close`).

7. **Суверенный сетевой стек, межсетевой экран JinnWall SPI и криптография PKI:**
   - Сетевой стек IPv4, TCP, UDP, ARP, DHCP и DNS на чистом Rust для сетевых адаптеров VirtIO-Net и Intel E1000.
   - Межсетевой экран с контролем состояния сессий (**JinnWall SPI**).
   - Валидация цепочек сертификатов **PKI X.509** и защищенное рукопожатие **TLS 1.3** (RFC 8446) с криптографическим протоколом HKDF-SHA256/384.

8. **Нативные приложения пространства пользователя (Ring 3):**
   - **Jinn Browser:** Графический веб-браузер без зависимостей от библиотек языка C, оснащенный движком разметки HTML/CSS, HTTP-клиентом, локальным кэшем, закладками и журналом переходов в каталоге `/disk/browser/`.
   - **Aladdin Shell:** Интерактивный терминал с утилитами системной диагностики (`sysinfo`, `vfs`, `net`, `ps`, `mem`).
   - **Aladdin Wallet:** Некастодиальный Web3-кошелек с детерминированной генерацией ключей по стандартам BIP-39/BIP-44, работающий в изолированном адресном пространстве Ring 3.

## Структура репозитория

```text
jinn/
├── Cargo.toml            # Манифест корневого рабочего пространства микроядра
├── limine.conf           # Конфигурация загрузчика Limine v2
├── build.rs              # Скрипт сборки и линковки ядра
├── apps/                 # Нативные приложения и сервисы пользовательского пространства (Ring 3)
│   ├── aladdin-server/   # Оконный сервер Aladdin Desktop (Композитор Ring 3)
│   └── ola-mundo/        # Jinn Browser (browser.rs) и Aladdin Wallet (wallet.rs)
├── sdk/                  # Aladdin SDK и клиентские библиотеки для Ring 3
│   └── aladdin-sdk/      # Обертки системных вызовов, графики, событий и IPC
├── contracts/            # Смарт-контракты BEP-20 / EVM и набор тестов Hardhat
│   ├── contracts/        # JinnToken.sol, JinnVesting.sol, JinnRewardDistributor.sol
│   ├── test/             # Модульные тесты и проверка инвариантов безопасности EVM
│   └── scripts/          # Скрипты развертывания для BSC Testnet/Mainnet
├── tools/                # Утилиты разработки и эмуляционные модули
│   ├── jinn-web3/        # jinn-web3 (CLI) и jinn-web3d (демон Ring 3)
│   └── jda-sim/          # Симулятор конвейеров DAG и бенчмарки SMP
├── web/                  # Официальный веб-портал Jinn OS (jinn-os.dev.br / GitHub Pages)
├── docs/                 # Архитектурная документация, ADR и отчеты об аудитах
└── src/                  # Исходный код ядра Jinn (Ring 0)
    ├── main.rs           # Точка входа ядра (_start) и запуск подсистем
    ├── gdt.rs            # Таблица дескрипторов сегментов GDT и TSS (Ring 0 / Ring 3)
    ├── idt.rs            # Таблица векторов прерываний IDT и обработчики ISR/IRQ
    ├── syscall.rs        # Канонический диспетчер системных вызовов (Syscalls 0..85)
    ├── scheduler.rs      # Вытесняющий планировщик задач
    ├── ipc.rs            # Неблокирующая статическая система передачи сообщений
    ├── memory/           # Аллокатор физических страниц (Buddy), куча ядра и PML4
    ├── drivers/          # Драйверы (PIT, LAPIC, Клавиатура, Мышь PS/2, IDE, PCI, VirtIO, E1000)
    ├── net/              # Стек TCP/IP, фаервол JinnWall SPI, TLS 1.3 и PKI X.509
    └── vfs/              # Виртуальная файловая система (FAT32, Ext2, LRU BlockCache)
```

## Сборка и запуск

### Требования к окружению
- **Инструментарий Rust:** Компилятор версии `nightly` с установленным таргетом `x86_64-unknown-none`.
- **Эмуляция и скрипты:** `qemu-system-x86_64`, PowerShell 7+ (Windows/Linux) или Python 3.

```bash
# Установка таргета для bare-metal разработки на x86_64
rustup target add x86_64-unknown-none
```

### 1. Компиляция микроядра и пользовательских программ
Запустите единый скрипт автоматической сборки ядра, пользовательских сервисов Ring 3 и генерации загрузочного диска FAT32:

```powershell
# Из корня репозитория
.\scripts\build.ps1
```

### 2. Запуск в виртуальной машине QEMU
Запустите систему в эмуляторе QEMU с эмуляцией аппаратных компонентов:

```powershell
# Стандартный запуск с графической средой Aladdin Desktop и сетью
.\scripts\run.ps1

# Стресс-тестирование в условиях жестких ограничений памяти (например, тест 64MB RAM):
.\scripts\run.ps1 -Memory 64M
```
